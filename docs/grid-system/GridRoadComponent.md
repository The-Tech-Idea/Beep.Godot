# GridRoadComponent

Grid-system component (a `Node2D` implementing `ISaveable`, `[Tool][GlobalClass]`) that stores player-built roads/paths per cell, draws them, and is the movement-cost source `GridNavigationComponent` reads back. The doc comment frames it generically — "dirt paths, roads, rails, trails, or any top-down/isometric route network" — and it is saveable by default (`ParticipatesInSave = true`, joining `SaveableHelper.Group` in `_Ready`) so a road network persists across a save/load cycle under its own `SaveKey` (`"grid_roads.state"`) in `GameStateData.GameData`, independent of the fixed per-player Combat/Movement/Inventory slots that `ISaveable`'s own doc comment describes as the interface's usual shape — a road network is naturally singleton per map, so the `GameData` dictionary slot fits it without needing a per-entity key.

Each road cell carries a `RoadRecord(string Kind, float CostMultiplier)`; `CanBuildRoad` gates new roads against `GridCellDataComponent`'s blocked flag and against `GridTerrainRules.MatchesAny` on `BlockedTerrainKinds`, which defaults to `GridTerrainRules.DefaultBlockedTerrainKinds()` — the shared "build-side" list, as opposed to `GridNavigationComponent`'s own hand-written blocked list that deliberately drops `shallow_water` (see that file's notes). `MinimumCostMultiplier` is a small dirty-flagged cache: its doc comment states directly that `GridNavigationComponent` reads it once per visited cell inside its A* heuristic, and recomputing it by walking every road on every read used to make pathfinding scale with the size of the road network instead of the size of the search — so it's only recomputed when a road is added, changed, or cleared.

## Public API
- `[Signal] RoadChanged(int x, int y, string kind, bool hasRoad)` / `RoadsChanged()` / `RoadRejected(int x, int y, string kind, string reason)` — `RoadRejected`'s only current reason is `"unroadable_terrain"`, raised from `TrySetRoad`.
- `[Export] NodePath GridPath / CellDataPath` — wires to `GridProjectionComponent` (drawing) and `GridCellDataComponent` (build gating), each falling back to a scene-wide find.
- `[Export] bool ParticipatesInSave` (default true), `string SaveKey` (default `"grid_roads.state"`) — save-system opt-in and slot key.
- `[Export] string DefaultRoadKind` (default `"dirt_path"`), `bool TreatCellDataBlockedAsUnroadable`, `bool TreatBlockedTerrainKindsAsUnroadable`, `Godot.Collections.Array<string> BlockedTerrainKinds` (default `GridTerrainRules.DefaultBlockedTerrainKinds()`), `float DefaultRoadCostMultiplier` (default 0.55, range 0.05–1).
- `[Export] bool DrawRoads`, `Color RoadColor/OutlineColor`, `float RoadWidthRatio`, `float OutlineWidth` — drawing appearance.
- `public float EffectiveDefaultRoadCostMultiplier / EffectiveRoadWidthRatio / EffectiveOutlineWidth` — sanitized reads of the corresponding exports.
- `public override void _Ready() / _ExitTree()` — joins/leaves `SaveableHelper.Group` per `ParticipatesInSave`; enables `_Process` only in the editor (for live redraw).
- `public override string[] _GetConfigurationWarnings()` — warns on an unset `GridPath`, an out-of-range `DefaultRoadCostMultiplier`, or an empty `SaveKey`.
- `public override void _Draw()` — draws every road cell as a shrunk polygon (via `GridProjectionComponent.CellCorners`, scaled by `RoadWidthRatio` toward the cell center) plus an optional outline; no-op when `DrawRoads` is false.
- `public void SetRoad(Vector2I cell, bool hasRoad)` — convenience: `true` builds `DefaultRoadKind` at the default cost, `false` clears.
- `public void SetRoad(Vector2I cell, string kind, float costMultiplier = -1f)` — thin wrapper over `TrySetRoad` that discards the success bool.
- `public bool TrySetRoad(Vector2I cell, string kind, float costMultiplier = -1f)` — validates via `CanBuildRoad`, clamps the multiplier to `[0.05, 1]`, stores the record, invalidates the cost cache, emits `RoadChanged`, redraws; emits `RoadRejected` and returns `false` if the cell can't take a road.
- `public bool CanBuildRoad(Vector2I cell)` — `true` when no `GridCellDataComponent` is resolved; otherwise checks the blocked flag and blocked-terrain-kind list per the two `Treat*` toggles.
- `public void ClearRoad(Vector2I cell)` / `public void ClearRoads()` — remove one or all roads, invalidate the cache, emit `RoadChanged`/`RoadsChanged`, redraw (no-op/no signal if nothing changed).
- `public bool HasRoad(Vector2I cell)`, `public string GetRoadKind(Vector2I cell)`, `public float GetTraversalCostMultiplier(Vector2I cell)` (1 when no road), `public int RoadCount`.
- `public float MinimumCostMultiplier` — cached minimum `CostMultiplier` across all roads (1 if none), recomputed lazily on a dirty flag.
- `public Godot.Collections.Array<Vector2I> GetRoadCells()` / `public Godot.Collections.Array<Godot.Collections.Dictionary> GetRoads()` — cell list, and cell+kind+cost dictionaries.
- `public Godot.Collections.Dictionary CaptureState()` / `public void RestoreState(Godot.Collections.Dictionary state)` — versioned (`version = 1`) road-list snapshot/restore.
- `public void LoadRoads(Godot.Collections.Array roads, bool clearExisting = true)` — bulk-loads roads from either bare `Vector2I`/`Vector2` entries (defaulting kind/cost) or `{cell, kind, cost_multiplier}` dictionaries; each entry is re-validated through `CanBuildRoad` before being stored.
- `public void Save(GameBuilder.GameStateData state)` / `public void Load(GameBuilder.GameStateData state)` — `ISaveable` implementation; writes/reads `state.GameData[SaveKey]` via `CaptureState`/`RestoreState`, no-op if `SaveKey` is blank or (`Load`) the key isn't present/isn't a dictionary.

## Dependencies
- Resolves `GridProjectionComponent` (`CellToWorld`, `CellCorners`, `ToGlobal`/`ToLocal` for drawing) and `GridCellDataComponent` (`HasFlag`, `GetTerrainKind`) via `NodePath` or scene-wide find.
- Calls `GridTerrainRules.Normalize` and `GridTerrainRules.MatchesAny` (shared helper, also used by `GridNavigationComponent`) and defaults `BlockedTerrainKinds` from `GridTerrainRules.DefaultBlockedTerrainKinds()`.
- Implements `ISaveable` and joins `SaveableHelper.Group` so a `GameStateManagerComponent`-style save system discovers it by group membership rather than by tree walk.
- Confirmed from this batch: `GridNavigationComponent.Search.CostFor`/`StepCost` calls `GetTraversalCostMultiplier(to)` per step, and `BuildSearch()` reads `MinimumCostMultiplier` for its A* heuristic's admissible floor — this file is called into by `GridNavigationComponent`.

## Notes
- `LoadRoads` silently drops any entry that fails `CanBuildRoad` at load time — if a cell's terrain/blocked state changed between when a road was saved and when it's loaded (e.g. the underlying `GridCellDataComponent` data was edited), that road is dropped from the restored network with no signal, warning, or return-value indication beyond `RoadChanged` simply never firing for it. Worth flagging alongside the terrain-engine batch's `Rebuild()` silent-failure note as the same class of caller-invisible outcome.
- `BlockedTerrainKinds`'s default (`GridTerrainRules.DefaultBlockedTerrainKinds()`) versus `GridNavigationComponent`'s own hand-written, `shallow_water`-excluding list is the concrete evidence behind the "two different lists" design called out in that file's Notes — confirmed here from the actual export default.
- Runtime redrawing relies on every mutating method (`TrySetRoad`, `ClearRoad`, `ClearRoads`, `LoadRoads`) calling `QueueRedraw()` directly; `_Process` only forces redraws in the editor (`Engine.IsEditorHint()`), so there is no per-frame redraw loop at runtime — consistent with `DrawRoads` being a mostly-editor/debug visualization rather than the game's primary road rendering.
