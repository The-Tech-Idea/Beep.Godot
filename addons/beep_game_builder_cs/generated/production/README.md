# Approved production packs

This folder intentionally contains no approved packs yet. Candidates live in dev.
A pack may enter here only after user visual approval, calibrated connection tests,
Godot resource validation and a passing non-production dependency check.

Required pack folders: sources, runtime and godot. An approved manifest records
stable IDs, source hashes, dimensions, connection types, animation timing, validation
evidence and reviewer/date. Do not use this folder as a staging shortcut.
