# RPG Demo

Playable top-down RPG sample built on `addons/beep_game_builder_cs/templates/scenes/rpg_main.tscn`.

It copies two Kenney roguelike spritesheets into `examples/rpg_demo/assets/` so the scene is self-contained.

Run:

```powershell
H:\dev\Godot\Godot_v4.7-stable_mono_win64.exe --path . examples/rpg_demo/rpg_demo.tscn
```

Move with `WASD` or arrows. Collect the herbs and use the weather panel to switch rain, storm, snow, hail, sand, and leaves.
