# Hill Prefab 1

`Hill Prefab 1 - Soft Grass` is a visual-only front-facing 2.5D hill pack
based on the rounded grassy mound reference.

The pack contains soft grass hill sprites only. It does not include rocks,
ramps, stairs, paths, collision, navigation, or walkability metadata.

## Godot Template

Use:

`res://addons/beep_game_builder_cs/templates/scenes/hill_prefab_1_creator.tscn`

The template uses the existing visual prefab component in custom-manifest mode:

- `MaterialTheme`: `Custom`
- `PackManifestPath`: `res://addons/beep_game_builder_cs/generated/hills/soft_grass/authored_prefabs/hill_prefab_1/hill_prefab_1_manifest.json`
- `BasePrefabId`: `hill_large`
