beep_game_builder_cs

The C# game-builder addon provides reusable components, generated scene templates, a data-driven skin system, a Game UI Kit, save/load state resources, weather and atmosphere systems, project generation, and Beep-specific MCP commands.

Core

Project generation, file helpers, screen generation, skin catalog, game metadata, save-state data, data binding, command history.

ECS

Gameplay, controller, world, area trigger, inventory, combat, progression, genre, and state components.

UI

HUDs, screens, widgets, theming, transitions, effects, settings, save/load menus, and data binders.

Kit

Drop-in and custom-drawn controls styled by skin catalog data, with shared panel headers, keyboard focus, visible focus cues, bounded wrapped text, and reusable dynamic minimum sizing that updates when exported layout properties change.

beep_ui

The GDScript addon exposes BeepPreset, BeepThemeApplier, BeepUIEffect, BeepWidgetFactory, and BeepToastHost.

It ships 22 presets: Modern, SciFi, Cartoon, Classic, Desert, OilGas, Sea, Sports, Soccer, Fantasy, Horror, Nature, Space, Military, Steampunk, Retro80s, Pixel8Bit, Winter, Cyberpunk, Japan, Toxic, Candy.

BeepUIEffect supports slide, shake, pulse, bob, flash, glitch, rotate, fade, typewriter, bounce, and offset effects.

MCP

godot_mcp owns transport and write gates. beep_game_builder_cs registers 41 Beep commands for catalog discovery, components, game state, scene editing, screenshots, texture baking, screen generation, and kit migration.

Safe defaults keep editor writes, runtime writes, and node method calls disabled. URL and token can be overridden with GODOT_MCP_BRIDGE_URL and GODOT_MCP_BRIDGE_TOKEN.

Review Findings

  • Build gate: root project excludes generated and test artifacts; clean build reports 0 warnings and 0 errors.
  • Tween presets: TweenComponent exposes 22 presets and implements all 22.
  • Lifecycle: kit MCP commands unregister during addon shutdown.
  • Preset registry: beep_ui inspector choices come from the preset registry.
  • Token hygiene: project settings no longer store a concrete MCP token.
  • Editor startup: headless editor smoke enables and disables all three addons without logged errors.
  • Dock API: Game Builder uses EditorDock and no longer suppresses obsolete dock API warnings.
  • UI kit headers: KitPanel, KitPanelContainer, and KitCollapsiblePanel use one shared panel header renderer.
  • UI kit focus: custom interactive controls support keyboard focus, visible focus rings, and keyboard activation/navigation across slots, tabs, knobs, books, wheels, radar charts, trees, level paths, and segmented controls.
  • UI kit text: dialog bodies, speech bubbles, tooltips, toasts, and item-card descriptions use shared wrapped text handling.
  • UI kit sizing: reusable kit controls report theme-aware minimum sizes, notify containers when exported layout dimensions change, and KitContextMenu supports keyboard popup behavior.
  • Reference check: template and skin resource references resolved.
